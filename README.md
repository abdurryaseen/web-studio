# Grant Street Websites

Marketing site for Grant Street Websites — a studio that designs and builds websites.

Plain HTML/CSS/JS, no build step. Open `index.html` directly or serve the folder with any static server.

## Structure

- `index.html` — single-page site: hero, work, pricing, contact
- `styles.css` — styling
- `script.js` — nav toggle, footer year, contact form stub
